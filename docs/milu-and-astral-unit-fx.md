# 流星灵狐·弥露与两名星穹棋子的专属特效

2026-10-22 新增正式可购买的 **1 费 流星灵狐·弥露**（`milu`），星穹／刺客／魔法。由星砂构成的四足星兽，尾部拖曳流星光带。当前正式名单 29 名，星穹有奥瑞斯、黑星咒术师、星铠守卫、弥露四名不同成员，能够自然激活 3 人档，后续成员仍待设计。

## 星跃

向自身相邻、靠近当前目标的空格位移 **1 格**，落地立即对当前目标造成 **120／180／270 魔法伤害**，不附带控制。法力 **0／60**。没有相邻空格时原地施放并命中当前目标。

| 基础属性 | 数值 |
| --- | --- |
| 生命／攻击 | 550／40 |
| 护甲／魔抗 | 25／25 |
| 攻速／射程 | 85%／1 格 |
| 法力／普攻回蓝 | 0／60；10 |
| 暴击 | 25% |

沿用当前技能施放门槛：目标在近战范围、蓝满且攻击冷却结束时施放。相邻空格按与当前目标的六边格距离排序，同距离按行、列稳定选择。位移和伤害在同一逻辑 Tick 完成，不因视觉尾迹延迟；没有额外范围伤害、控制或不可选中。正常参与法术加成、增伤、目标魔抗、护盾及既有刺客职业规则，统计归属弥露。

## 两人的特效动画

专门绘制并接入四张原生透明素材，与用户提供的两张立绘保持相应配色：

- 星铠守卫：蓝金中空星盾旋转、呼吸，彗星拖尾沿冲刺方向前进，敌人按固定击飞时间抛起并落下。保持 [恒星壁垒](star-armor-guard.md) 的 250／375／550 物理加成护盾、4 秒持续、最多 2 格冲刺及固定 0.75 秒击飞。
- 弥露：白紫星砂流光连接起点与相邻落点，当前目标身上产生四角星芒爆发；原地施放仍显示命中星芒。

![实际战斗动画](evidence/astral-unit-fx/both-skills-preview.gif)

素材完整提示词、原生输出与 SHA-256 见 [特效归档](../art-source/astral-unit-fx/provenance.json)。两张用户立绘均保持原图像素不变，见 [守卫来源](../art-source/star-armor-guard/provenance.json)、[弥露来源](../art-source/milu/provenance.json)。透明边缘和中空盾壳检查见 [alpha-qa.json](evidence/astral-unit-fx/alpha-qa.json)。

动画由正式战斗事件驱动，和模拟器共用时钟，支持暂停及倍速。冲刺中断、死亡、战斗结束和视图重绑会清理状态；使用数量受限的节点复用，反复施放不持续创建节点。混编机械棋子时，守卫不会错误显示熔炉冲刺特效。

## 验收证据与范围

[针对性回归](evidence/astral-unit-fx/regression-results.json) **17 组脚本全部通过**，涵盖两名新棋子的三档数值、双边六方向移动、无空格／边缘、护盾独立层与到期、固定且每人一次击飞、单体即时魔法伤害、抗性／统计、配置校验、星穹／职业／日辉／暗影／机械、商店合成及存档展示兼容。其中现有应用回归为 **75 passed，0 failed**。初次回归使用的旧棋盘替身缺少 `showAstralFields`，补齐测试接口后通过；首轮结果保留在 [regression-first-pass.json](evidence/astral-unit-fx/regression-first-pass.json)。资源检查通过 187 张纹理、29 名棋子、30 种野怪；Creator TypeScript 脚本诊断无错误。

[真实浏览器验收](evidence/astral-unit-fx/browser-acceptance.json)在 Creator 的实际预览中使用合法 4 人上限部署四名正式星穹成员，确认 3 人档 7 个星穹格、两张立绘及四张特效实际加载；鼠标打开两人的角色和技能面板；检查暂停、两倍速、冲刺中断、战斗结束、反复施放及重绑清理，无浏览器脚本错误。重复 12 轮产生 24 次施法，运动特效保持 3 个复用槽。

动画截图阶段只在独立浏览器内临时补满法力、关闭普攻并停止无关角色移动，以隔离效果；面板截图保留正式基础属性。这些状态不写入用户存档。预览目标有两重甲坦克羁绊带来的 25 魔抗，因此弥露的基础 120 魔法伤害实际扣血 96，与正式伤害公式一致。未执行完整测试集、Android 构建或设备运行，也没有进行全爬塔平衡资格验证。

通用设计校验对两名新棋子均为 **0 ERROR／5 WARN**：守卫沿用当前 1 费坦克的 700 生命、30 攻击、40 双抗及 40／100 法力；弥露采用当前低费刺客模型 550 生命、85% 攻速、25 双抗，并使用用户确认的 0／60 法力，与旧通用表的默认值存在差异。这些差异有意保留。当前整份名单的旧通用校验为 12 ERROR／97 WARN，其中既有 12 项错误未由本次清除；没有为消除旧告警重调其他棋子。详见 [弥露](evidence/astral-unit-fx/design-validator-milu.txt)、[守卫](evidence/astral-unit-fx/design-validator-guard.txt)和 [全名单](evidence/astral-unit-fx/design-validator-full.txt)输出。
