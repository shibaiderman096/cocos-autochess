# 羁绊表现、人口提示与战斗加时

战斗计时和人口提示规则见下文。[2026-10-17 构建与预览记录](evidence/hud-overtime/acceptance.md)使用已删除的旧阵容，仅保留计时与界面修复的历史证据，不代表当前羁绊或名单的验收。

## 界面

- 羁绊详情根据效果类型显示属性图标和彩色数值；当前羁绊规则见[羁绊总览](traits.md)。
- 删除详情底部“同名棋子只计一次 · 备战席不参与”的说明文案，计数规则保持原有实现。
- 人口数字从 64 号放大到 86 号，相对棋盘中心上移 28。准备阶段未满员时常亮蓝色；满员后收起常驻提示，拖动时仍显示普通颜色；超员显示红色。战斗中收起常驻人口提示。
- 正式推进战斗时，顶部阶段框转换为剩余时间进度条：正常阶段蓝色，显示 `战斗 30s` 并逐步减少；加时切换为橙色，重新从 `加时 15s` 减少。结算及下一回合恢复阶段标题。

## 已确认的战斗规则

`battle.json`：`combatSeconds: 30`，`overtime: {seconds: 15, attackSpeedBonus: 1, damageAmp: 1}`，50ms Tick 下总上限 `maxTicks: 900`。

加时强化同时作用于双方存活棋子。进度 `p = clamp((当前Tick - 600) / 300, 0, 1)`：额外攻速为 `+p` 次/秒，额外伤害增幅为 `+p`，因此加时结束达到界面显示 +100% 攻速（+1.00 次/秒）和 +100% 伤害增幅。最终攻速继续遵循已有 500% 上限。伤害增幅与原有伤害增幅相加，作用于普通攻击及所有经过统一伤害出口的技能伤害。

强化使用独立的运行时字段，不写回棋子基础配置，不被技能结束时清除攻速覆盖。新建战斗实例从零开始计算，避免跨回合叠加。战斗属性详情读取实时攻速和伤害增幅。

倒计时取模拟 Tick，不使用独立墙钟；倍速同步推进计时。45 秒内先满足胜负条件则正常结算，第 45 秒仍未分出胜负才判平局。调用方可设置更短的诊断上限，但不能把战斗延长到配置的 30＋15 秒之外。
