# 法咏者

魔法术士自动归属：`role: caster` + `damageType: magic`。只统计不同 ID 的上场成员，同 ID 副本计数一次、每个副本均可受益，备战席不参与。双方独立、最高档替换低档，开战锁定。

| 人数 | 法术加成 | 每次参与击杀回复法力 |
| --- | --- | --- |
| 2 | +15% | 8 |
| 4 | +30% | 12 |
| 6 | +50% | 16 |
| 8 | +80% | 20 |

法术加成沿用项目百分点规则，与基础属性、装备、阵营法术加成相加。当前成员为冥灯女巫、黑星咒术师、瑟琳、奥瑞斯、弧光维修姬，能自然达到2/4人档；6/8人档通过不同ID的测试成员验证，没有改动角色归属或允许同名重复计数。

## 已确认结算规则

- 参与者必须在目标死亡前最近5秒内对其造成过实际生命伤害，且死亡结算时自身仍存活。正好5秒包含在内，5秒后失效；重复命中刷新窗口。普攻、技能、持续伤害均可参与，不限制个人伤害类型。
- 只吸收护盾、零实际生命伤害不计入；暗影全场、日辉裁决等独立阵营伤害的代表单位不会因此成为参与者。
- 每名参与者对同一名敌人只结算一次；多个目标分别结算，非参与成员不回蓝。双方同一帧死亡不能获得或保留回蓝，也不能复活。
- 施法前摇 `pendingCast` 或 `manaLocked` 期间将羁绊回蓝暂存，解除后补回。固定步进在行动前和行动后检查解锁，实际解除的当帧即可补回；不改变普通回蓝的锁蓝规则。
- 回复不超过最大法力，多余部分丢弃，不留待下一次施法。死亡清空暂存，新战斗重置参与记录和暂存量。
- 回蓝通过独立 `trait_mana` 事件显示蓝色 `+N法力`，数值为实际回复量；法力条继续使用战斗快照。不会把回蓝当作治疗或伤害统计。
