# 商店购买升星提示

商店棋子卡片右上角用金色描边和高亮星星显示购买这一张后的升星结果：两星为 `★★`，三星为 `★★★`。计入场上与备战席同名棋子；一次购买能够先合成两星、再合成三星时直接显示三星。不能触发新合成时不显示。

`BattleStage.refreshShopUI` 从真实持有棋子生成提示，`BattleUI.refreshShop` 同步显示并清除空槽或不再满足条件的提示。购买、出售材料和刷新商品后沿用现有商店刷新流程。同一棋子出现在多个商店槽时分别计算，购买后其他槽的提示也会更新。

`OwnedUnits.purchaseUpgradeStar` 在持有棋子的独立副本上调用实际合成规则，不修改玩家棋子、装备或UID。在副本中先处理已有的延后合成，再添加一张一星棋子，因此不会把战斗中早已凑齐的材料误报为本次购买带来的升星；真实战斗中的合成仍延后到战斗结束。

提示只表达合成结果，购买仍使用原有金币、备战席与战斗状态规则。
