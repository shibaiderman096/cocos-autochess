# 九项新增开局奇遇

基于 GitHub `master` 的 `92ee70f9611365b8873e87fef7898d5988c579d5`，Cocos Creator 3.8.8。
原有六项加本次九项组成十五项候选池，开局仍随机三选一。所有随机来自 RunRandomContext，候选和计数沿用当前存档。
数值位于 `assets/resources/config/run.json` 的 `openingEncounter.effects`。旧配置未提供 effects 时仍使用六项候选。

| 奇遇 | ID | 规则 |
| --- | --- | --- |
| 精兵强将 | vacancy | 开战按实际人口上限（含装备）减上场实例数取非负值，最多8层，每层+10%增伤和减伤。预览与战斗共享快照；战斗中买卖不改变层数。 |
| 羁绊共鸣 | resonance | 只比较已激活羁绊的去重成员人数；人数最多的一项计数+1，可跨档。不新增成员，不让未激活羁绊凭空激活。并列按ID排序后，以本局种子和关卡ID随机选择一项；同关预览/存档恢复一致。 |
| 三星登神 | ascension | 己方开战上场三星棋子+40%增伤、+20%减伤；备战席、敌军和低星排除，开战后升星下次生效。 |
| 荒野丰收 | abundance | 所有 monster 关，包括开局和强力野怪，胜利宝箱总预算乘1.5后向下取整，例如3→4、5→7；先提升总价值再抽取物品，不逐件复制或舍入。精英、Boss、探索者宝箱及普通战斗收入不加成。 |
| 首领狩猎 | bossHunt | 精英在敌军预算生成之前改成Boss，生成预算、装备、关卡标签和宝箱来源/价值都采用Boss规则。原精英不再发第二份奖励。保留原关卡ID/阶段位置；原生10-10终局Boss无宝箱例外不变，被替换的其他关卡享有完整Boss宝箱。无额外旧版治疗或装备选择。 |
| 再续前缘 | secondLife | 全队每场仅首次死亡触发，3秒（向上取整到tick）后以最大生命30%向下取整、至少1HP复活。同期多人死亡按现有单位ID顺序确定首次。保留ID、属性、装备、战斗成长、击杀统计及一次性技能/装备已用标记；清理施法、法力、护盾、灼烧、控制、临时技能状态。不重放开场效果。尸体不占格，原位被占则在全棋盘按六角距离、y、x找最近空格；无空格等待空位。等待期间即使全灭也不提前结算，敌方全灭也等待复活；超时/外部结束取消等待。死亡仍正常计入击杀，复活不计治疗。表现层通过 revive 事件恢复可见性并停止旧死亡渐隐。 |
| 同道来援 | kindred | 从第2大阶段进入时，以当时上场阵容比较最高已激活羁绊；并列按ID排序后使用阶段种子随机选一项，再从该羁绊仍可抽取且有库存的成员中随机取一张1星卡。尊重特殊商店解锁与真实卡池扣除；备战席满时沿用 unitReserve，后续收集和合成。无已激活羁绊或无库存则该阶段不发放、不补发。lastGiftStage 防止重复进关、读档及调试回跳刷取；调试跨阶段只处理到达阶段，不补中间阶段。 |
| 复利无穷 | compound | 利息=floor(开战前金币/10)，无5金币上限；战斗中买卖和本次奖励不改变本场利息，界面预估一致。安全整数上限仍受检查。其余奇遇保持原经济规则。 |
| 好运连连 | luckyRoll | 每次成功付费棋子刷新和实际发生的关卡切换刷新独立50%概率增加1张免费刷新券，不自动刷新。消耗免费券不再抽取新券，防止自循环。锁店未刷新、失败操作、初始商店、读档恢复、秘境行商刷新均不触发。关卡ID和刷新序号决定随机结果，不影响商店/战斗随机流；免费次数和序号存档。 |

增伤/减伤沿用现有加法属性及最终减伤上限规则，不绕过既有固定伤害定义。
当前存档采用严格配置指纹；本次 run.json 变更后，旧配置指纹的进行中存档仍会被现有系统拒绝，需要新开一局，不做静默迁移。

## 验证

- `node tests/extended-encounter-tests.cjs`：九项效果、边界、恢复与确定性。
- `tests/opening-encounter-tests.cjs`：候选覆盖扩展为十五选三的455种组合，并校正第2/3阶段既有5金币入场补贴断言。
- `npx tsc --noEmit -p tsconfig.json`：使用本机 Creator 3.8.8 已生成的声明检查全部代码。
- `node tools/check-resources.cjs`：资源引用检查。
- 全量回归与未修改基线对照结果见交付验收说明；没有将旧测试失败描述为全部通过。尚未做实际Creator画面、自然通关或Android设备验证。
