# P1-B 离线战力标定结果

版本：enemy-power-v1；模型哈希：f5f4e1d435eb2dcd9abc6b9f85fe6b7b5922f5ae065a5b6610748d1418c0bba4。不接入实际敌军生成。

## 方法与范围

真实 BattleSim，保持当前属性、技能、装备效果不变。971组对战，每种子换边×实例顺序4场；三个合法距离环境按种子轮换。共77680场逻辑样本。训练1～16；独立验证17～20，同一 matchup+seed 不跨集合。

拟合观测是 0.5×log((初始生命A+实际治疗A)/(初始生命B+实际治疗B)) + 0.5×log((实际伤害A+1)/(实际伤害B+1))。共享时长在DPS比值中相消；+1生命平滑零伤害。该量是公开的近似尺度，不是战力真值。胜负不直接转换成价格，而用于训练 logistic 胜率映射和独立验证。使用有锚点、ridge=0.001、最多4000次坐标下降的联合最小二乘。

基准为所有实际1费1★无装备棋子的估值中位数100；费用baseline由各档中位数计算，不强制随费用递增。每单位、星级和已测装备组合保留独立点；close/medium/far环境各自使用同一中位数归一约定。

## 镜像与置信度

镜像165组，最大换边偏差0.000，最大先实例化偏差0.500；偏差超过0.05的条目121组，其中先实例化区间不含0.5的45组。区间未做165项多重比较校正，不直接宣称系统性公平缺陷；平衡交换后的A/B对称也不等于消除了实例顺序效应。具体位置/星级/装备及胜负平、余血、伤害、治疗、时长见 observations.json 与 analysis.json。镜像不参与定价。

| 置信度 | 组合点数 |
| --- | --- |
| high | 0 |
| medium | 0 |
| low | 525 |

high需要至少400个独立训练seed、多个对手、较小拟合残差；medium表示样本足够但覆盖有限；low包括5费仅一名身份、三★、强距离敏感、零伤害删失或大残差。sampleCount是实际对战数，independentSeeds是独立seed数，不能混用。

## 产物和边界

model保存在 enemy-power.json；原始逐seed缓存位于指定缓存目录，不塞进运行时配置。observations.json为分组统计，validation.json为未参与拟合的验证结果，analysis.json为异常与标签，provenance.json记录源码/配置哈希及seed集合。performance.json单独记录实际新跑场数、缓存命中和wall clock，不参与确定性哈希。

当前游戏不读取新模型。P1-C预算生成、智能布阵、Boss/Elite生成、装备奖励和正式机器人都未实现。
