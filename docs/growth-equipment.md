# 成长与法力装备

2026-10-23：新增三件普通装备，均进入普通装备奖励、Boss 装备选择及 3 金币特殊商店。装备图鉴、背包、穿戴详情、奖励面板读取同一配置与属性图标组件。

| 装备 | 基础属性 | 被动 |
| --- | --- | --- |
| 磐生壁垒 | +200 最大生命，+10 护甲，+10 魔抗 | 磐石之躯：最终最大生命每满 100 点，每件额外增加 1 点护甲和魔抗 |
| 炽羽叠锋 | +10% 攻击速度，+10% 物理加成 | 锋芒渐炽：每次普攻每件增加 2 个百分点物理加成，持续本场战斗 |
| 秘涌法典 | +5 法力/秒，+10% 物理加成，+10% 法术加成，-10 最大法力 | 奥术溢流：每次施法，每件对当前攻击目标造成最终最大法力值 250% 的魔法伤害 |

磐生壁垒按星级、装备固定生命、百分比生命、永久生命成长和羁绊加成后的最终最大生命计算，多件分别生效。生命不会因受伤下降，双抗不会随当前生命下降；新双抗也参与深渊重铠的护甲阈值判定。

炽羽叠锋沿用攻速百分数的项目规则：+10% 为 +0.10 次/秒。物理加成按百分点累加，作用于后续物理伤害，包括普攻与物理技能；技能本身不会获得普攻层数。每次普攻只显示一层，多件分别提供数值；图标层数复用已有叠层展示，下一场战斗重置。

秘涌法典回蓝与职业回蓝相加，走固定 Tick；初始法力超过新的最大法力时截断。用户确认多件减蓝后最大法力最低为 10，原本无蓝条的棋子仍为 0。额外魔法伤害打当前攻击目标，按减蓝后的最大法力计算，并正常受法术加成、魔抗及减伤影响。治疗、护盾等友方技能也触发，每次施法仅一次，范围命中、技能完成与多段伤害不会重复触发。例如原最大法力 50，穿一件后为 40，基础溢流为 100；本装备提供的 10% 法术加成后，对零魔抗且无其他加成的敌人造成 110 点伤害。

森灵庇护仅在生命严格低于 50% 期间每秒回复 1.5% 最大生命。达到 50% 及以上时停止；再次低于时重新计时一秒。每个装备槽结算时重新检查当前生命，防止同 Tick 后续副本在已过阈值时继续回复。

图片原件保留在 `art-source/equipment/`，运行时使用保留透明度的 128×128 PNG 与 SpriteFrame。三件装备直接复用用户提供的图案。

存档允许装备目录追加与普通池扩展，保留金币、装备和已冻结的奖励；已有装备机械字段、敌人配置或其他策略变化仍参与兼容性校验。新装备没有加入敌人已标定装备列表；原敌军装备预算模型沿用已有数据。
