# 羁绊系统

当前保留暗影、日辉、机械先驱、星穹及九种职业羁绊。磁轨猎手·零七与阿特拉斯使迅武师自然达到2人档。火影忍者、原住民及其全部成员，连同铁傀儡、末影人，已于 2026-10-19 删除。

新增[星穹](astral-trait.md)羁绊，奥瑞斯、黑星咒术师加入并保留原有归属。新增 1 费星铠守卫和流星灵狐·弥露后已有四名成员，可以激活 3 人档；其余成员后续设计；星穹格、10 人档陨星及两名新棋子的专属美术和动画已接入。

配置入口为 `assets/resources/config/battle.json`；双方按不同上场成员分别计数，备战席不计数。

2026-10-23 删除布隆达、雷昂、影缝刺客、裂魂斩将后，暗影、日辉各有 8 名原生成员，档位和数值保持不变。黑星咒术师、奥瑞斯需特殊商店购买解锁。新装备[万象共鸣徽记](special-shop-and-emblem.md)可向当前携带者授予选定羁绊：首次穿戴在下方商店区四选一，优先已激活且人数高的羁绊；选择绑定装备，卸下失去、转移保留。按不同角色 ID 计数，未穿戴的同名副本不继承装备授予的羁绊。
