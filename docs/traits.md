# 羁绊系统

当前保留暗影、日辉及五种职业羁绊。火影忍者、原住民及其全部成员，连同铁傀儡、末影人，已于 2026-10-19 删除。

配置入口为 `assets/resources/config/battle.json`；双方按不同上场成员分别计数，备战席不计数。

- [暗影](shadow-trait.md)
- [日辉](sunlight-roster.md)
- [职业羁绊与当前成员](class-traits.md)

本次名单和机制发生变化，启用预算敌军和阵型系统的旧配置存档继续通过配置身份校验拒绝不兼容恢复；legacy 模式沿用原有名单清理，不恢复已删除棋子。历史平衡实验证据保留原输入，不代表当前名单或平衡结果。
