# 羁绊系统：火影忍者

新增“原住民”羁绊：七名基础职业棋子、3/5/7 档、按开战前后排分配生命/减伤或攻速/增伤，见 [原住民设计与验证](native-trait.md)。本页其余内容描述原有火影羁绊。

新增五个自动职业羁绊：重甲坦克、斗士、迅捷射手、神射手、刺客，见 [职业羁绊规则与验收](class-traits.md)。

界面续改：各档加成已改成图标与彩色数字，移除同名棋子的说明文案。该轮按用户要求暂不测试或预览；本页原有验证记录属于之前版本。新一轮改动及待验收项见 `docs/combat-hud-overtime.md`。

配置入口：`assets/resources/config/battle.json` 的 `traits`。纯逻辑入口：`battle/Traits.ts`，由 `BattleSim` 对双方独立计算。界面入口：`ui/TraitPanel.ts`，左侧与背包互切，点击/悬停可查看效果和拥有者。

列表仅显示至少一名携带者上场的羁绊。备战席携带者不使条目出现；1–2 名上场忍者显示灰色未激活徽章，最后一名携带者下场后隐藏条目并关闭该羁绊的点击/悬停详情。未上场角色仍可在已显示的羁绊详情中作为拥有者展示。

| 上场种类 | 徽章 | 物理加成 | 法术加成 | 额外效果 |
| --- | --- | --- | --- | --- |
| 0–2 | 未激活 | 0 | 0 | 无 |
| 3–4 | 黄铜 | +15% | +15% | 无 |
| 5–6 | 白银 | +30% | +30% | 无 |
| 7–9 | 黄金 | +50% | +50% | 无 |
| 10 | 棱彩 | +80% | +80% | 每秒恢复 2% 最大生命 |

仅火影忍者成员获得加成。同一配置 ID 多份只计一次，各形态是不同棋子；备战席不参与。同一个阵容内的所有成员副本都能受益。各档效果替换，不逐档累加。双攻与原有物理/法术加成、装备加成按百分点相加，不修改基础攻击力，不作用于真实伤害。棱彩回血不吃法强，受最大生命上限限制，不复活死亡单位，并通过统一 heal 事件回放、计入治疗统计。

开战时锁定档位，死亡不降档；准备阶段上下场、存档恢复均重新计算，避免叠加污染。详情属性读取同一份预览战斗数据，备战席不显示上场加成。羁绊配置进入已有 battle 配置身份检查；旧局机制不一致时沿用项目现有拒绝恢复规则，不静默改写存档。

目前成员：学员鸣人、漩涡鸣人、仙人鸣人、少年佐助、宇智波佐助、少女小樱、宇智波鼬、宇智波斑，共 8 种。正常内容当前可激活最高 7 人档；10 人档留待扩充角色，测试用的未来 ID 不会加入卡池。

初版平衡依据：3 人小投入提供温和的 15% 对应伤害增益，5/7 人以阵容位置和角色选择为代价递增至 30%/50%；10 人追求档提升到 80%，并提供 20 秒累计至多 40% 最大生命的持续恢复（需要持续存活且有损血）。双攻不互相乘算，避免混伤单位获得二次放大。当前数值为可调初版，尚未完成新羁绊下的完整爬塔平衡资格测试。

徽章直接使用用户提供的透明 PNG，原文件拷贝至 `assets/resources/art/ui/trait_badges.png`。运行时用明确矩形截取五个区域，无重绘和像素修改；“火”字由界面文字叠入。

验证：`node tests/trait-tests.cjs`、`node tests/ui-interaction-tests.cjs`、`node tests/regression-tests.cjs`、`npx tsc --noEmit -p tsconfig.json`、`npm run build:web`。编译后的网页测试实际执行羁绊计数，并防止 Creator 把 Set 展开误编译为数组拼接。

本次实际横屏浏览器已验收未激活/黄铜徽章、首字嵌入、三种忍者上场、详情四档/名单、背包切换与详情收起、棋子详情双攻均为 15%，并完成一场战斗进入 1-2。白银/黄金/棱彩状态使用自动 UI 测试；棱彩持续回血使用合成十种成员进行逻辑测试，不声称当前卡池能组成十人羁绊。截图保存在 `docs/evidence/traits/`。

最终全量测试为 44 组通过、5 组失败：skill-attack-isolation（斑首次命中随攻击力变化）、skill-presentation（元数据星级数值差异）、power-calibration（旧校准期望）、p3-equipment（历史阵容候选数差异）、medium-economy（机器人刷新目标期望）。逐项移除 traits 后仍然失败，对照证据保存在 `temp/trait-disabled-*.log`，全量记录为 `temp/trait-full-test.log`，未改写历史快照或放宽断言。
