# 上场羁绊与基础攻击力调整（2026-10-17）

## 羁绊显示

只在至少一名携带者上场时显示该羁绊。忍者 1/2 人显示未激活灰色徽章，3 人开始激活；全部忍者都在备战席时，列表没有火影忍者条目。最后一名携带者下场时，同时关闭该羁绊的点击或悬停详情，不显示空列表提示文案。显示筛选在 TraitPanel 内完成，逻辑仍可计算 0 人状态，战斗开场锁定档位的规则保持一致。

## 初版验证与范围（以下为 v1 历史记录，不代表 v2 已重跑）

- 攻击力专项：17 个棋子逐项匹配定位/伤害方向/费用；51 项真实普通攻击覆盖 1/2/3 星。
- 对照输入逐字段验证，17 个棋子仅 `atk` 改变，生命、技能、费用、定位、伤害类型、攻速、双抗和蓝条均保持原值。
- 羁绊 UI 自动交互：0 人不显示；1/2 人显示灰色；最后携带者下场关闭点击/悬停详情；已有五徽章、切换、档位与拥有者检查。
- 对局回归：74 项通过；羁绊逻辑专项通过；TypeScript 类型检查与网页构建通过。
- 实际 1280×720 浏览器验收：仅弓手上场、忍者在备战席时没有火影条目；学员鸣人上场后显示灰色 1/3，详情面板攻击力为 40；将其拖回备战席后条目消失。四张截图位于 `docs/evidence/trait-attack-update/`。
- 12 个独立种子 10417001–10417012，medium 机器人、3 阶段、默认预算敌人与自动布阵，分别运行修改前/后配置。两侧均 12/12 通关，共 168 回合记录，其中各 156 场实际战斗全部获胜。平均战斗时长从约 4.69 秒变为 6.33 秒，最终最低生命均为 20。第一种子重复运行的完整记录一致。结果及修改前输入保存在 `temp/trait-attack-update/`。
- 此实验仅检查前三阶段流程与变化，不是后期平衡资格测试。旧 `enemy-power.json` 未重新校准，后期难度与物理输出降低的影响尚待新校准和完整爬塔样本确认。
- M1 伤害公式测试的一星鸣人预期随攻击力由 50→40 更新为 33（20 护甲）；对称冒烟阵容在种子 42 下出现第 477 tick 双双阵亡，因此终局检查同时验证有存活者的胜利、全灭平局或达到 1200 tick 的超时平局，不再错误要求对称阵容每次必须决胜。
- 最终完整测试为 45 组通过、5 组失败，日志 `temp/trait-attack-update/full-test-final.log`。失败套件仍为调整前已有的 skill-attack-isolation、skill-presentation、power-calibration、p3-equipment、medium-economy；未改写这些历史期望。初次全量中由本次攻击力变更暴露的 M1 公式期望和冒烟平局假设已经更新并复测通过。
- 技能自带的旧全局校验器仍按“费用统一攻击力”检查，产生预期的攻击力偏离 WARN；本次使用项目内新基准进行严格验证，没有修改全局技能文件。该旧校验器还存在改动前同样能复现的 `healing_channel` 治疗加成图标 ERROR：调整前 1 ERROR/22 WARN，调整后 1 ERROR/33 WARN，证据为 `unit-validator-before.log` 与 `unit-validator.log`。未通过放宽规则或改技能内容隐藏该错误。
