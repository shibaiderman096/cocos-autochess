## 技能数值与结算

表内均为 1/2/3 星基础值。物理、魔法伤害各自读取对应加成，再进入增伤、技能暴击资格、减伤及双抗流程。攻击力只影响普通攻击。护盾默认跟随棋子伤害方向，可由 `shieldScaling` 覆盖，护盾不吃伤害增幅。

| 技能 | 基础值与行为 |
| --- | --- |
| 深渊壁垒 | 护盾 160/240/360，双抗 +15/20/30，持续 4 秒；破裂或到期对自身周围 1 格造成 80/120/180 物理伤害。 |
| 夜羽贯星 | 朝目标方向贯穿至棋盘边缘；首名敌人 150/225/350，后续 90/135/210 物理伤害。 |
| 魇灯领域 | 自身护盾 260/390/600，另两名最低生命比例友军各 130/195/300；持续 4 秒。领域随自身移动，半径 2 格，敌人攻速 -15%/-20%/-25%。 |
| 影缝 | 跃到最远敌人背后，连续三刀，每刀 90/135/210 物理伤害，间隔 0.15 秒；完成后 3 秒内该目标死亡返还 35 法力。 |
| 裂魂断界 | 朝目标方向，前方 2 格、总角度 60°，造成 260/390/650 物理伤害；按目标已损生命比例增加伤害，最多 +50%。 |
| 幽焰连斩 | 6 秒内获得 +35%/+50%/+75% 攻速，接下来 4 次普攻保留物理部分、分别附加 55/85/140 魔法伤害；第四击在目标周围 1 格另造成 140/210/350 魔法伤害。 |
| 蚀月处决 | 锁定全场最低生命比例敌人，造成 360/560/2240 物理伤害；目标生命严格低于 35% 时伤害 ×1.5。 |
| 百鬼冥灯 | 三盏半径 1 格，间隔 0.3 秒，各造成 160/240/960 魔法伤害并恐惧 0.75/1/2.5 秒；同次施法重复命中同一敌人的后续灯伤害 ×0.6。 |
| 黑星坠灭 | 3/3/9 颗，间隔 0.2 秒，每颗半径 1 格，伤害 240/360/3000；同次施法重复命中的后续星伤害 ×0.5。最后落点半径 2 格坍缩另造成 180/270/6000 魔法伤害。 |
| 虚痕跃迁 | 最多 5/7/20 次，每次间隔 0.15 秒并造成 100/150/1500 魔法伤害；每个不同敌人最多留一层虚痕，结束时各引爆 160/240/4000 魔法伤害。 |

边界约定：

- 护盾按到期时间先后吸收，保留装备及其他来源护盾。铁卫重复施法会结束旧盾、爆发一次，再建立新盾，双抗不叠加；同一 Tick 破盾后，后续伤害使用已撤销加成的双抗。
- 守灯人保护友军没有距离限制；领域减速只在范围内生效，多领域取最强值。施法者死亡会结束领域，已给其他友军的护盾保留至到期。
- 影缝每刀独立判定技能暴击；最后一刀击杀也能返蓝，完成前的较早击杀不进入“结束后 3 秒”窗口。返蓝只触发一次，可由其他单位击杀目标触发。
- 三盏灯在施法时确定落点，优先选敌人最密集的不同敌方格；不足三个不同格时可复用。恐惧实际驱使目标逃离落点，并阻止攻击/施法。
- 黑星每颗落下前重选最密集敌方格，平手按坐标和 ID 稳定决策。已经发出的冥灯和黑星不因施法者死亡而取消。
- 虚痕优先未命中目标，再按生命比例和 ID 选择，不连续跳同一目标。全程不可选中，剩单目标、无可选敌人或没有合法背后空位时结束连跳并引爆现有标记。引导被打断或施法者死亡则中止；引导结束后恢复可选中。
- 贯穿箭经过格子边界时采用稳定规则；恰好沿外缘飞行选棋盘内侧格子，避免浮点取整提前截断。

## 立绘与表现

原始十张 PNG 未重绘、未裁写像素，尺寸均为 1086×1448，透明 RGBA。源文件名、对应角色、运行路径和 SHA-256 见 [manifest.json](../art-source/shadow-roster/manifest.json)。文件名后缀映射：1 铁卫、2 守灯人、3 斩将、4 刃侍、5 夜猎、6 弩姬、7 咒术师、8 女巫、9 影缝、10 掠杀者。

`ArtPaths` 注册正式资源；`UnitView` 保持立绘宽高比，商店、详情及羁绊头像通过运行时区域读取原图头部。`BattleReplayer` 消费技能脉冲，播放黑雾弹、坠星、紫色斩击和范围爆发；领域环随施法者移动。黑雾炮弹、棋盘雾和侵蚀环沿用已接入的项目内素材，详见 [暗影羁绊](shadow-trait.md)。

## 验证及复现

- `node tests/shadow-roster-tests.cjs` 通过：十人明确值、全部星级、双方施法、确定性、合法传送、分段伤害、恐惧、护盾生命周期、公共伤害链、非法配置拒绝、素材哈希与映射。贯穿箭覆盖射程内全部 1854 种起点/目标组合。
- TypeScript 检查通过；资源检查通过（144 个注册资源、27 个棋子、8 个野怪）；差异格式检查通过。
- 最终全量测试 **53 组通过、9 组失败**。[原始日志](evidence/shadow-roster-v3/full-tests.log)保留；失败组与接入十棋子之前的记录一致：regression、ui-interaction、skill-attack-isolation、stage-progression、run-session、run-sim-cli、power-calibration、p3-equipment、medium-economy。涉及已有 `cc` 模拟依赖、界面位置及旧数值预期等问题，本次未扩展修复。
- 通用设计校验器 **3 ERROR、64 WARN**，没有全绿。[日志](evidence/shadow-roster-v3/unit-validator.log)中两个 ERROR 来自已有治疗描述 `{治疗+:healBonus}`，另一个是虚痕的单段三星倍率未达到通用 20 倍门槛。v3 明确使用多段总量设计，保留其数值；两名敌人完整命中时基础总量为二星 1530、三星 38000。WARN 包含旧基线与用户明确攻击力/法力的差异。
- 编辑器当前主场景的 TypeScript 诊断为 0 错误；`validate_scene` 综合结果因扫描到历史错误日志而失败，不视为场景验收通过。[记录](evidence/shadow-roster-v3/scene-validation.json)。

独立预览场景为 `assets/shadow-preview.scene`，固定种子 1018；编辑器预览服务运行时访问 `http://localhost:7456/?scene=435b77cf-3386-46e2-bc2d-e689a03e5dfd`。场景直接读取正式十人成员，仅在内存里设置满蓝和高血敌人用于演示，不创建 RunSession、不读写玩家存档。可切换 3/5/7/10 档、1/2/3 星、播放/暂停、前进一秒，点击棋子打开真实详情，点击技能图标打开真实技能弹窗。
