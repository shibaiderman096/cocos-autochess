# 暗影羁绊

正式成员现已接入 v3 十棋子，`battle.json` 中 `pendingMembers: false`。成员、技能、立绘映射及最新验证见 [暗影十棋子接入记录](shadow-roster-v3.md)。不同棋子 ID 各计一次，同名副本不重复计数。

暗影棋子常年与黑暗相伴，获取暗影的力量。各档保留低档效果：

| 上场数量 | 效果 |
| --- | --- |
| 3 | 暗影棋子普攻命中使目标沾染暗影，双抗降低 30%。 |
| 5 | 暗影棋子的物理加成、法术加成各增加 30 个百分点。 |
| 7 | 沾染暗影的目标每秒降低 2 个百分点伤害增幅，累计最多降低 20 个百分点。 |
| 10 | 黑雾包围棋盘；每秒全体友军额外增加 20% 攻速，累计最多 +200%；每 0.5 秒全体可命中的敌军受到 100 固定真实伤害。 |

## 结算约定

- 侵蚀在普攻命中结算后附加，持续至本场结束。首次命中自身不吃新附加的破甲，后续物理与魔法伤害均可受益；技能本身不附加侵蚀。
- 30% 破甲按当前双抗乘 0.7 计算，重复命中不继续相乘、不刷新衰减计时。施加者死亡后侵蚀仍保留。
- 伤害增幅衰减按首次沾染后的完整一秒结算；基础增伤为 0 时可降至 -20%，基础 +50% 时最低为 +30%。
- 10 档在开战后每完整一秒增长攻速，每 0.5 秒结算一次伤害，不要求敌军先沾染暗影。友军包含非暗影棋子；双方各自统计，档位固定到本场结束。
- +20% 攻速 = +0.20 次/秒；+200% 为本羁绊额外加成上限 +2.00 次/秒，总攻速仍受 5.00 次/秒上限限制。
- 固定伤害不吃双攻、增伤、暴击、双抗或减伤，不触发施加者吸血、刺客斩杀。保留护盾吸收、不可选中保护、保命装备、死亡和真实伤害统计。伤害统计单列为“暗影羁绊 4★”，不计入任一成员的个人伤害；来源成员阵亡后仍可记录全场效果。
- 无成员的待设计羁绊不改变现有战斗配置身份；一旦分配任何成员，仍按完整战斗配置检查存档兼容性。

## 复现与验证

打开 `assets/shadow-preview.scene` 预览，或在编辑器预览服务器运行时访问：

`http://localhost:7456/?scene=435b77cf-3386-46e2-bc2d-e689a03e5dfd`

这是独立、固定种子 1018 的测试场景，现使用正式十名暗影棋子及其技能。满蓝及高血敌人仅用于场景演示，不创建 RunSession、不读写玩家存档。可切换 3/5/7/10 档、1/2/3 星、打开棋子/技能/羁绊详情、播放/暂停、前进一秒。初始暂停在 2 秒，10 档友军累计攻速 +40%；侵蚀时间取决于各棋子实际普攻命中时刻。最新截图与验证见 [v3 接入记录](shadow-roster-v3.md)。
