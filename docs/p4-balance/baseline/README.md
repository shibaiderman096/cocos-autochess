## 初步结论与边界

Stage3与Stage6显著高于85%/50%的目标；保留该事实，不通过削弱机器人或隐藏失败来达标。当前Stage3只解锁1费1星，且原始预算长期低于人口地板。提高growth等旋钮可能被原可行上限截断。下一步先用模型/生成器确认这一约束，再定义有边界的静态预算/解锁参数实验。

原始逐局JSONL、逐波CSV、阶段CSV及Wilson区间在runs-500各机器人目录。无未来信息、免费资源、绕过卡池或动态橡皮筋。P1-B模型、单位、技能、装备效果、经济/卡池公式仍未修改。
