# 浮空棋境

Cocos Creator 3.8.8 / TypeScript 自走棋 PVE 原型。打开 `assets/scene.scene` 运行战斗舞台。

M2 界面素材位于 `assets/resources/art/ui_m2/`，已接入商店卡片、锁店遮罩、出售区、经验条、波次轨道、备战席及结算面板。底栏压缩为 112 像素，左侧阵容面板和说明已移除；棋子属性在右侧查看，战斗与倍速按钮位于右下角。面板和按钮使用九宫格，加载期间保留矢量底图。SVG 源文件、尺寸清单及原包预览保留在 `art-source/ui_m2/`；预览图仅为素材参考，实际玩法和布局以游戏为准。

准备阶段可招募、购买经验（4 金币换 4 经验）、调整站位、锁店、点击棋子在右侧查看属性。实际拖动棋子时，底部商店变为出售区并显示返还金额，拖入后松手出售；取消或移出后松手恢复商店。人口只在拖动时显示，并按目标位置预览上阵人数，超上限标红。每波战斗后结算金币和经验，点击“下一波”继续；整局结束后可重开。

- 共 7 波，初始生命 20。战败或超时平局时，每个存活敌人扣 2 点生命；同时全灭不扣生命。
- 生命归零判失败；完成最后一波且生命大于零判胜利。
- 同 tick 的普攻和技能伤害统一结算，双方受到致命伤也能完成本 tick 的行动。
- 脚底光圈区分敌我：我方青绿、敌方红色。星级使用素材包中的 1 / 2 / 3 星徽章，在血条上方显示；三张同星棋子自动合成，支持连续升至 3 星。
- 锁店保留下一波商品和空位；手动刷新仍花 2 金币换商品，锁定状态保留。
- 1 费棋子按合成张数全额出售；其他费用升星后按总价减 1 金币。出售返还 1 / 3 / 9 张基础卡。

| 费用 | 1 星售价 | 2 星售价 | 3 星售价 |
| --- | --- | --- | --- |
| 1 | 1 | 3 | 9 |
| 2 | 2 | 5 | 17 |
| 3 | 3 | 8 | 26 |

10 个棋子：1 费战士、弓手、斥候、卫士；2 费剑客、游侠、祭司；3 费法师、术士、统领。复用现有战士、弓手、法师图片并加色彩区分，技能复用单体 / 范围伤害与最近 / 低生命目标管线。

配置位于 `assets/resources/config/`：`units.json` 配棋子，`skills.json` 配技能，`battle.json` 配星级倍率与生命规则，`waves.json` 配敌人阵容、星级和属性倍率（生命、攻击、护甲、魔抗、技能伤害）。战斗中断后刷新回到当前波准备阶段；结算后刷新恢复战报，不重复发奖励。

验证：`npm test` 运行战斗、经济、商店、回合流程和界面联动测试；`npm run batch -- 1000 42` 运行无渲染批量战斗。`core/`、`battle/` 不依赖 Cocos，可单独运行。波次难度仍需要实际游玩调优。
