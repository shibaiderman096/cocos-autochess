# 浮空棋境

Cocos Creator 3.8.8 / TypeScript 自走棋 PVE 原型。入口为 `assets/main.scene`，点击“开始游戏”进入 `assets/scene.scene` 战斗舞台。主界面通过 − / + 设置本局阶段数（3～99，默认 3），有未结束的存档时可“继续游戏”；开始新游戏会重置本局存档。

M2 界面素材位于 `assets/resources/art/ui_m2/`。底栏高 150 像素，使用云顶式排版：左侧购买经验按钮内合并等级、经验数值及进度条，下方为刷新按钮，两个按钮均为 148×62，使用经验 / 刷新 / 金币图标；中间横排 5 张商品。金币位于商品正上方，左侧按白 / 绿 / 蓝 / 紫 / 金显示 1～5 费刷新概率，锁店位于右上角，远征指令在右下角。概率与实际抽卡共用当前剩余卡池；耗尽的费用档显示 0，其他费用按权重归一化。面板和按钮使用九宫格，加载期间保留矢量底图。SVG 源文件、尺寸清单及原包预览保留在 `art-source/ui_m2/`。

界面统一采用 1280×720 设计坐标，并随窗口尺寸全屏缩放。点击开始战斗后，顶部阶段栏显示 1 秒准备倒计时和进度条动画，不遮挡棋盘，不受倍速影响，结束后才推进战斗。顶部小关进度轨道在无操作 3 秒后隐藏，触摸、点击、按键或切换小关时重新显示；阶段编号和生命信息保持显示。

准备阶段可招募、购买经验（4 金币换 4 经验）、调整站位、锁店。战斗期间仍可购买 / 刷新 / 锁店 / 买经验，并可调整或出售备战席棋子；参战棋子本场不可移动或出售，购买触发的升星在下一场生效。备战席操作只刷新备战视图，不重建模拟器、战斗视图或回放游标。结算期间暂停商店交互。

点击己方或敌方棋子在右侧打开详情面板：头像、星级、费用、血量 / 法力进度条、攻击、护甲、魔抗、攻速、攻击距离、法强、暴击率、吸血、伤害增幅、伤害减免及技能。属性按两行五列排列，射程放在头像信息区，装备放在底部。点击技能图标查看技能详情，再次点击或关闭按钮收起；点击攻速图标查看攻速规则。战斗中血量和法力实时更新。拖动棋子时商店变为出售区并显示返还金额，拖入后松手出售；取消或移出后松手恢复商店。拖动时目标棋盘格高亮，可放置显示青绿、不可放置显示红色，松手或取消后清除。人口提示加粗并居中棋盘，仅在拖动时显示，准备阶段按目标位置预览上阵人数，超上限标红。战斗结束会撤销尚未完成的拖拽。每小关结算金币和经验，阶段栏下方显示胜利 / 失败 1 秒后自动进入下一小关的准备阶段，等待时间不受战斗倍速影响；整局结束时胜负提示同样显示 1 秒，保留重开和返回主界面按钮。

- 每局至少 3 阶段：第 1 阶段为 3 小关极弱野怪，第 2 阶段为 5 小关，之后每多一阶段增加 1 小关，最多 10；默认共 14 小关。顶部显示“阶段-小关”和本阶段轨道。开局仅赠送 1 个一星一费战士，位于备战席，拖上棋盘即可参战。
- 敌我使用相同基础配置与升星倍率，不再叠加阶段或小关属性倍率。第 2～3 阶段为 1 费 1 星，第 4～5 阶段为 2 费 1 星，第 6～7 阶段为 3 费 2 星，第 8～9 阶段为最高已实现费用的 2 星，第 10 阶段起为最高费用 3 星。当前最高已实现费用为 5。
- 从第 2 阶段第 1 小关起，敌方人口为 1；每完成 3 小关加 1，跨阶段累计，最多 10。第 10 阶段开始每阶段增加 5% 伤害增幅和减免，减免最多 80%。增加本局阶段数只追加后续关卡。
- 物理加成默认 0，物理伤害（含普攻）乘以 (1 + 物理加成 / 100)；法强默认 0，魔法伤害乘以 (1 + 法强 / 100)；真实伤害不受这两项加成影响；暴击率默认 0.25（25%），普攻暴击默认造成 150% 伤害；吸血默认 0，按扣除过量部分后的实际伤害回复，不能复活本 tick 已受到致命伤害的单位。增幅、减免默认 0，所有伤害均乘以 (1 + 增幅) × (1 - 减免)，真实伤害忽略双抗但仍受增幅和减免影响。
- 初始生命 20。战败或超时平局时，每个存活敌人扣 2 点生命；同时全灭不扣生命。
- 初始金币 0；每小关结算基础收入为 min(2 × 当前阶段数, 10)（第 1 / 2 / 3 阶段分别为 2 / 4 / 6 金币）。另保留胜利奖励、利息、连胜 / 连败奖励；继续游戏保留已有金币，重开归零。
- 生命归零判失败；完成最后一波且生命大于零判胜利。
- 同 tick 的普攻和技能伤害统一结算，双方受到致命伤也能完成本 tick 的行动。
- 脚底光圈区分敌我：我方青绿、敌方红色。星级使用素材包中的 1 / 2 / 3 星徽章，在血条上方显示；三张同星棋子自动合成，支持连续升至 3 星。
- 锁店保留下一波商品和空位；手动刷新仍花 2 金币换商品，锁定状态保留。
- 1 费棋子按合成张数全额出售；其他费用升星后按总价减 1 金币。出售返还 1 / 3 / 9 张基础卡。

16 个棋子：1 费战士、弓手、斥候、卫士；2 费剑客、游侠、祭司、少女小樱、少年佐助；3 费法师、术士、统领；4 费宇智波佐助、宇智波鼬；5 费末影人。棋子和腐衣僵尸、白骨弓手、岩隙蠹虫、赤瞳巨蛛各有独立资源映射；敌我使用相同人物资源，由阵营光圈区分。技能复用单体 / 范围伤害与最近 / 低生命目标管线。

配置位于 `assets/resources/config/`：`units.json` 配棋子和五项新属性，`skills.json` 配技能，`battle.json` 配星级倍率、暴击倍率和生命规则。`run.json` 配首阶段野怪、阶段小关数、初始棋子及 `enemyProgression`（费用/星级节奏、人口增长、摆位和后期增减伤）；`waves.json` 提供阶段名称，战斗阵容由成长配置和可购买棋子生成。野怪按开局一星一费战士的 25% 生成生命、攻击、双抗、法强及法力属性，攻速固定为 0.75，保留各自射程和外观，不进入商店和卡池。当前生命为 175、攻击为 13.75、护甲为 10、魔抗为 5、攻速为 0.75、法强为 0，暴击率为 6.25%。阶段收入按阶段编号计算，小关不重复提升阶段编号。阶段数写入本局存档，刷新 / 继续 / 重开均保留；战斗中断后刷新回到当前小关准备阶段，结算后刷新恢复阶段栏下方的胜负提示，等待 1 秒后自动进入下一小关，不重复发奖励。旧版每阶段 10 小关的存档保留所在阶段；超出新关数时恢复到该阶段最后一小关。

验证：`npm test` 运行战斗、经济、商店、回合流程和界面联动测试；`npm run batch -- 1000 42` 运行无渲染批量战斗。`core/`、`battle/` 不依赖 Cocos，可单独运行。波次难度仍需要实际游玩调优。

浏览器构建：修改源文件后运行 `npm run build:web` 更新 `build/web-desktop`，再强制刷新浏览器；已构建的网页不会自动读取源文件。构建包含实际编译代码的回归检查，也可单独运行 `npm run test:web`。网页外层填满视口，棋子详情显示法强、暴击率、吸血、增伤和减伤。

安卓原生 APK：运行 `pwsh -File tools/build-android.ps1 -JavaHome <JDK目录>`。默认使用 Cocos Creator 3.8.8、`D:\Android\Sdk`、NDK 27.2.12479018、CMake 3.22.1 和 SDK 36，其他路径可通过参数覆盖；项目生成的 Gradle Wrapper 使用 8.11.1，Gradle 缓存保存在 `temp/android-gradle/`。输出为 `build/releases/autochess-android-arm64-debug.apk`，采用调试签名，支持 ARM64 / Android 5.0 及以上，横屏运行，包名 `com.shibaiderman.autochess`。APK、工具缓存和本机编辑器插件不提交到源码仓库。

右侧本场统计采用横条，上方切换伤害 / 承伤 / 治疗，下方切换己方 / 敌方，按当前统计值排序。伤害和承伤按物理橙色、魔法蓝色、真实白色分段，治疗为绿色；伤害按实际扣血、治疗按实际回血统计。结束和下一关准备时保留，下一次战斗开始才清空。打开棋子详情时暂时替换统计表，关闭详情后恢复。

### 装备测试入口

左侧背包存放未装备的装备与后续道具，24格一页，可翻页。准备阶段打开左上角“Debug 菜单”→“获取装备”，选择装备免费放入背包，将图标拖到棋子（棋盘或备战席），或先选棋子再点击背包图标装备。背包与详情中的装备图标固定为24像素，详情图标点击卸下；棋子血条下方以12像素图标显示已携带装备。装备栏位于详情面板内，不遮挡战斗按钮。鬼索图标使用用户提供的图片，原始 WebP 保留在 `art-source/equipment/guinsoo.webp`，运行时无损转换为 PNG。战斗中锁定更换。每个棋子最多3件；升星溢出、出售与卸下的装备回到背包并随存档保存。后续道具使用 backpackItems 存档字段（consumable 类型），与装备共用背包展示。恢复存档时清理未知装备 ID；背包点击和拖拽使用显示项对应的真实库存索引。

攻速加值直接相加：+5%攻速 = +0.05次/秒，与基础攻速无关。例如基础0.7次/秒，增加5%后为0.75次/秒。装备和技能的攻速加成都采用此规则。

每件鬼索提供10%法强和+0.1次/秒攻速，每次普攻额外叠加+0.05次/秒，重复装备分别生效，每场重新计数，攻速仍受5次/秒上限限制。

不死图腾提供200生命、10护甲、10魔抗。准备阶段在“Debug 菜单”→“获取装备”中选择“不死图腾”，拖到棋子或选中棋子后点击装备；悬停或按住图标查看说明。使用用户提供的原始PNG图标，并采用最近邻过滤保留像素风格。

每场战斗仅触发一次：携带者生命严格低于最大生命5%时触发，致命一击保留1生命；立即获得10%最大生命护盾，0.3秒（6 Tick）不可选中，并在5秒（100 Tick）内逐步回复10%最大生命。护盾按装备后的最大生命计算，持续到耗尽或战斗结束；回血不受眩晕打断且不超过生命上限。不可选中时跳过新的选敌与已排队的定向命中，已有灼烧及范围波及仍可伤害护盾/生命。重复携带叠加基础属性，保命效果全身共享一次。触发显示装备名称，护盾存在时显示金色护盾圈，不可选中时棋子半透明。`npm test` 包含图腾效果、背包装备/存档和显示回归；已在浏览器预览核对图标、领取、装备及生命/双抗加成，战斗触发效果由自动化回归验证。

珠光护手提供20%法术加成、35%暴击率；无尽之刃提供20%物理加成、35%暴击率。在“Debug 菜单”→“获取装备”中选择“珠光护手”或“无尽之刃”获得装备，原始WebP保留于 `art-source/equipment`，运行时使用无损PNG图标。两件均解锁所有伤害技能的暴击（物理、魔法、真实伤害、范围伤害和持续伤害），每次伤害独立使用携带者的暴击率与现有暴击倍率（默认150%）；治疗与护盾不暴击。基础25%加一件为60%，两件为95%，最多100%；同类属性相加，重复解锁只判定一次暴击，不额外提高暴击倍率。混合技能先分别计算物理/法术加成，再统一暴击和减伤；真实伤害仍不受这两项加成影响。装备说明、棋子属性及伤害技能详情同步显示相关规则。


### Debug 菜单

游戏左上角“Debug 菜单”默认收起，点击展开，四个页签集中提供调试操作，关闭后保留当前选择：

- 获取装备：从配置自动生成全部装备列表，准备阶段免费领取至背包；原背包底部的测试领取按钮移至这里。
- 调整阶段：选择阶段及小关后跳转，支持每次+1或+10阶段；范围1～99阶段，超出本局阶段总数会自动扩展，不改变已有阶段的阵容与数值。跳转取消当前倒计时/战斗/待结算跳关计时，回到目标关卡准备阶段；保留金币、经验、棋子、装备、商店与卡池，不发放跳过战斗的奖励。已有生命保留，失败后0生命使用初始生命重新测试。
- 获得金币：+10、+100、+1000，准备或战斗期间立即入账并保存；与存档一致，上限999999。
- 获得棋子：按费用排序、每页6项，可选择1～3星，准备阶段免费放入备战席。尊重卡池库存，分别消耗1/3/9张同名基础卡；备战席满且无法立即合并时拒绝领取，失败不扣卡、不扣金币。合并、装备溢出回包及出售返卡沿用现有规则。

拖拽中暂停调试修改。自动回归覆盖菜单折叠/页签/分页、金币及棋子存档恢复、库存守恒、满席合并、阶段扩展和战斗中跳转清理。
