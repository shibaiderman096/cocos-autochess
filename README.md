# 浮空棋境

Cocos Creator 3.8.8 / TypeScript 自走棋 PVE 原型。入口为 `assets/main.scene`，点击“开始游戏”进入 `assets/scene.scene` 战斗舞台。主界面通过 − / + 设置本局阶段数（3～99，默认 3），有未结束的存档时可“继续游戏”；开始新游戏会重置本局存档。

M2 界面素材位于 `assets/resources/art/ui_m2/`。底栏高 150 像素，使用云顶式排版：左侧购买经验按钮内合并等级、经验数值及进度条，下方为刷新按钮；中间横排 5 张商品。金币位于商品正上方，左侧按白 / 绿 / 蓝 / 紫 / 金显示 1～5 费刷新概率，锁店位于右上角，远征指令在右下角。概率与实际抽卡共用配置；当前没有 4、5 费棋子，相应概率为 0，其他费用按权重归一化。面板和按钮使用九宫格，加载期间保留矢量底图。SVG 源文件、尺寸清单及原包预览保留在 `art-source/ui_m2/`。

准备阶段可招募、购买经验（4 金币换 4 经验）、调整站位、锁店。战斗期间仍可购买 / 刷新 / 锁店 / 买经验，并可调整或出售备战席棋子；参战棋子本场不可移动或出售，购买触发的升星在下一场生效。备战席操作只刷新备战视图，不重建模拟器、战斗视图或回放游标。结算期间暂停商店交互。

点击己方或敌方棋子在右侧打开云顶式详情面板：头像、星级、费用、血量 / 法力进度条、攻击、护甲、魔抗、攻速、攻击距离（格）及技能。战斗中查看参战棋子时，血量和法力实时更新。拖动棋子时商店变为出售区并显示返还金额，拖入后松手出售；取消或移出后松手恢复商店。人口仅在拖动时显示，准备阶段按目标位置预览上阵人数，超上限标红。战斗结束会撤销尚未完成的拖拽。每小关结算金币和经验，点击“下一小关”继续；整局结束后可重开。

- 每局至少 3 阶段：第 1 阶段为 3 小关极弱野怪，之后每阶段 10 小关；默认共 23 小关。顶部显示“阶段-小关”和本阶段轨道。开局仅赠送 1 个一星一费战士，位于备战席，拖上棋盘即可参战。
- 初始生命 20。战败或超时平局时，每个存活敌人扣 2 点生命；同时全灭不扣生命。
- 生命归零判失败；完成最后一波且生命大于零判胜利。
- 同 tick 的普攻和技能伤害统一结算，双方受到致命伤也能完成本 tick 的行动。
- 脚底光圈区分敌我：我方青绿、敌方红色。星级使用素材包中的 1 / 2 / 3 星徽章，在血条上方显示；三张同星棋子自动合成，支持连续升至 3 星。
- 锁店保留下一波商品和空位；手动刷新仍花 2 金币换商品，锁定状态保留。
- 1 费棋子按合成张数全额出售；其他费用升星后按总价减 1 金币。出售返还 1 / 3 / 9 张基础卡。

| 费用 | 1 星售价 | 2 星售价 | 3 星售价 |
| --- | --- | --- | --- |
| 1 | 1 | 3 | 9 |
| 2 | 2 | 5 | 17 |
| 3 | 3 | 8 | 26 |

10 个棋子：1 费战士、弓手、斥候、卫士；2 费剑客、游侠、祭司；3 费法师、术士、统领。复用现有战士、弓手、法师图片并加色彩区分，技能复用单体 / 范围伤害与最近 / 低生命目标管线。

配置位于 `assets/resources/config/`：`units.json` 配可购买棋子，`skills.json` 配技能，`battle.json` 配星级倍率与生命规则，`run.json` 配首阶段野怪、每阶段小关数、初始棋子和跨阶段属性成长；`waves.json` 的阵容模板生成后续阶段，每阶段覆盖完整的 10 小关。野怪复用现有图片并加色彩区分，基础生命 30～60、攻击 1～3，不进入商店和卡池。阶段收入按阶段编号计算，小关不重复提升阶段编号。阶段数写入本局存档，刷新 / 继续 / 重开均保留；战斗中断后刷新回到当前小关准备阶段，结算后刷新恢复战报，不重复发奖励。

验证：`npm test` 运行战斗、经济、商店、回合流程和界面联动测试；`npm run batch -- 1000 42` 运行无渲染批量战斗。`core/`、`battle/` 不依赖 Cocos，可单独运行。波次难度仍需要实际游玩调优。
